# @vision-control/workspace-index

Node-only workspace file index: discovers source files, hashes them, and
indexes static CSS class-token origins for source resolution.

> Nx tags: platform:node, type:library, scope:workspace-index.

## Scripts

Run from the repository root:

```bash
pnpm build        # tsc -p tsconfig.build.json -> dist/
pnpm typecheck    # tsc --noEmit -p tsconfig.json
pnpm test         # vitest run
```
